# Ai-Desk-Robot-Tars-With-Pan-Tilt-Camera
I wanted to create a desk robot that you can ask things, chat with it, ask what is going on with the enviroment via camera that he can look around with 2 servos. I made it using a Raspberry pi 4 1gb, a Logitech web cam, PCA9685, MT3608, 1s lipo or 18650 or any 5V power supply ,MAX98357A and a 8ohm 5w speaker.
